⚡ Speed Tips

  • flash_attention_2 is fastest on Ampere+ GPUs; falls back to sdpa automatically if unavailable.
  • torch.compile speeds up steady-state generation after a slower first call.
  • Reusing the same reference clip skips re-encoding it every time.
  • bfloat16 is the fastest safe dtype on modern GPUs.
